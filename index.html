  1. เปิดแอป Telegram ค้นหา @BotFather

  3. เมื่อสร้างเสร็จ จะได้รับ HTTP API Token (คัดลอกมาวางในช่อง Bot Token)
ขั้นตอนที่ 2: หา Chat ID ของคุณ
  1. ค้นหา @userinfobot ใน Telegram แล้วกด Start
  2. บอทจะตอบกลับตัวเลข Id: xxxxxxxx (คัดลอกมาวางในช่อง Chat ID)
  3. สำคัญ: กดเข้าไปที่บอทที่คุณสร้างในขั้นตอนที่ 1 แล้วกดปุ่ม Start หนึ่งครั้ง เพื่อเปิดให้บอทส่งข้อความหาคุณได้
